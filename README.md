# Fiche d'intervention Kivoitoo

Appli installable (PWA) utilisée par les techniciens Kivoitoo pour remplir les fiches d'intervention sur téléphone.

- Fonctionne sans réseau : la page est gardée dans le téléphone et les fiches non envoyées partent toutes seules quand le réseau revient.
- Les fiches sont envoyées au script Google Apps Script de Kivoitoo (tableau, Drive, mails, Dolibarr).
- Aucune donnée client n'est stockée dans ce dépôt ; l'accès aux données demande le code de l'appli.

Installation sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
